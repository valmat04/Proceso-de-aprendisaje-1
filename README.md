Trabajo de practica

API REST de recuperación de humedales con Java 21, Spring Boot, PostgreSQL, JWT y Swagger.

El proyecto incluye Maven Wrapper, una colección de Postman y [los resultados de validación](ayquipaValentino/docs/VALIDACION.md): 18 pruebas aprobadas y comprobaciones HTTP con PostgreSQL real.

Las contraseñas y los tokens se configuran localmente y no están incluidos en el repositorio.
