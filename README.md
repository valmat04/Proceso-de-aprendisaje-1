# Proyecto ayquipaValentino

API REST de recuperación de humedales con Java 21, Spring Boot, PostgreSQL, JWT y Swagger.

## Descargar y abrir en IntelliJ

1. En GitHub, selecciona **Code → Download ZIP**.
2. Descomprime el archivo descargado.
3. En IntelliJ IDEA, selecciona **File → Open** y abre la carpeta `ayquipaValentino` o su `pom.xml`.
4. Selecciona JDK 21 e importa el proyecto Maven.
5. Sigue el [README del proyecto](ayquipaValentino/README.md) para crear `BDParcialAyquipa`, configurar tus variables privadas y ejecutar la aplicación.

El proyecto incluye Maven Wrapper, una colección de Postman y [los resultados de validación](ayquipaValentino/docs/VALIDACION.md): 18 pruebas aprobadas y comprobaciones HTTP con PostgreSQL real.

Las contraseñas y los tokens se configuran localmente y no están incluidos en el repositorio.
